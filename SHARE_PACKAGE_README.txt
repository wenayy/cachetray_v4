CacheTray Chrome Extension 1.7.5

Install for testing
1. Extract this ZIP to a folder.
2. In Chrome, open chrome://extensions.
3. Turn on Developer mode.
4. Choose Load unpacked and select the extracted folder (the folder containing manifest.json).

To publish through the Chrome Web Store, upload this ZIP in the Developer Dashboard.

This extension uses CacheTray's hosted transfer service for phone pairing, image/clip transfer and Pro billing. These services are operated separately from this ZIP; recipients do not get their own backend or storage account by installing it. Real payments are enabled on the service only when the operator deploys live billing configuration. Never enter sandbox test cards into a live checkout. No Dodo or Cloudflare private credentials are included in this ZIP.

The extension stores captures locally in Chrome by default. Phone transfers are explicit and temporary. Review the privacy policy and service configuration before redistributing to a wider audience.
