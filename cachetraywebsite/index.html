What it saves

Five types of content,
all automatically sorted.

CacheTray detects what you copied and puts it in the right category so you can filter and find it quickly.

🔗 Links
URLs & Links
Any URL you copy is saved as a clickable link with the site name shown. Useful for keeping docs, references, and resource pages close by.
notion.so › Meeting Notes
https://notion.so/workspace/Meeting-Notes-a1b2...

⌨️ Code
Code Snippets & Error Messages
Code is auto-detected — JavaScript, Python, Bash, SQL, stack traces, terminal output. It gets a code block preview and a one-click copy button.
const res = await fetch(url)
const data = await res.json()

🖼️ Images
Screenshots & Images
Copy or right-click any image on a webpage to save it. You get a thumbnail preview. Click to expand, then copy or download it. Images are auto-compressed to save space.

Create quick to-do items directly in CacheTray. Tap the circle to mark them done. Good for follow-up actions while you're in the middle of a session.
